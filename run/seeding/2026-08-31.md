### 1. TabNews — post
**Título:** Seu modelo “escala no teste” e morre com 100 usuários. Onde quebra primeiro.
**Corpo:**
Benchmark de 1 request é mentira útil. O sistema responde em 80ms no notebook e, com 100 concorrentes, a latência explode. Quase nunca é “o modelo ficou pior”. É fila de inferência, batch vazio, lock no tokenizer, ou o servidor serializando o generate.

Teste de 2 minutos: 1 request vs 20 simultâneos no mesmo endpoint. Se p95 sobe 10x e a GPU não chegou a 100%, o gargalo é o servidor, não o GGUF.

### 2. r/brdev — post/comment
**Título / ângulo:** GPU de R$8.000 rodando modelo de 3GB. O desperdício não é a placa.
**Corpo:**
Comprar 24GB pra servir um 3B quantizado é o equivalente a alugar um caminhão pra levar uma mochila. O modelo cabe em 8GB. O que você pagou a mais foi headroom de contexto, batch e um segundo modelo residente — se você não usa nenhum dos três, é dinheiro parado.

Meça VRAM alocada vs VRAM usada no generate. Se está em 4/24GB o dia inteiro, o upgrade certo era o modelo, não a placa.

### 1. r/LocalLLaMA — comment on a fresh thread about Copilot / credit burn / “why is my bill high”
**Draft:**
The credit dashboard is a lagging indicator. Copilot will happily re-index every open tab, every formatter save, and the whole chat thread — and the UI still says you are “within plan.” If your longest chat gets more expensive every reply, that is context growth, not a new model.

A 30-second check: close idle tabs, disable suggestion-on-save in the formatter, start a fresh chat. If spend drops, you were paying for index + context, not intelligence.
