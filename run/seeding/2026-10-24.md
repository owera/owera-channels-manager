### 1. r/LocalLLaMA — comment on a fresh agent-plugin or MCP-tool thread

Find a thread about plugins, MCP tools, or a manifest that runs setup before the tool exists. Do not start a new post.

**Draft:**

A plugin manifest that runs a shell before the tool has loaded is not a setup step. The shell is the tool. On our channel the short that held the watch in that cohort is exactly that order: the manifest executed, then the tool definition showed up, and the user never approved the command as a tool call. If your loader treats `setup` as data, check whether it is already a process.

### 2. dev.to — post

**Title:** An open Copilot chat is a running request

**Body:**

I treated Copilot Chat like a scratch buffer. It is not one. If the last turn is still an agent session, the pane can keep the request open while you are in another file, and that time is billed in AI credits. Code completions on the paid plans do not touch that pool. Chat, agent mode, and code review do.

The short walks through one idle session, not a pricing table. Worth closing the pane when you walk away from the agent, the same way you would stop a dev server.

## ch2 Rodrigo Recio (PT-BR)

### 1. TabNews — post

**Título:** 32 GB de RAM não salvam um modelo que não cabe na VRAM

**Corpo:**

Comprei memória achando que o gargalo era a RAM. O modelo não cabia na VRAM, então o resto ia para a memória do sistema e o token/s desabava. Mais pente não muda o tamanho do chip da placa.

O teste que ficou no canal: a máquina tinha 32 GB de RAM e a fila estava na VRAM. Antes de subir o contexto ou trocar o quant, vale olhar o que está residente na GPU e o que o sistema já comeu (Windows, navegador, o próprio runtime).

https://www.youtube.com/shorts/xpCy4qk7f3Q

### 2. r/brdev — post

**Título:** 7B cabe. 13B no mesmo PC, não.

**Corpo:**

A pergunta "qual modelo eu rodo" não é o nome do modelo. É o que sobra de VRAM depois do sistema. No teste, um dos dois subiu e o outro recusou na mesma máquina, sem trocar a placa.

Antes de baixar o 13B, olha o que já está na GPU. O Windows e o navegador comem um pedaço que a ficha técnica do modelo não conta. Se o 7B rodou folgado e o 13B caiu, o próximo passo é quantização ou contexto menor, não mais um pente de RAM.

https://www.youtube.com/shorts/8fBOeCTTysc
