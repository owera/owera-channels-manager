### 2. r/brdev — post/comment
**Título / ângulo:** Recarregar o modelo a cada prompt parece “IA lenta”. É I/O.
**Corpo:**
Load de 18 GB do SSD a cada pergunta não é “o modelo é pesado”. É o servidor morrendo entre requests, o keep-alive em 0, ou o Ollama descarregando pra caber outro blob. O generate em si pode ser 30 tok/s. O wall-clock é 40s porque você pagou o load de novo.

Olhe o log: se cada request reabre o GGUF, conserte o keep-alive antes de trocar a quant.

Short de ontem (t4):
https://youtu.be/C730IYwybhE

No seu setup, o modelo fica residente entre perguntas ou você paga o load toda vez?

### 3. LinkedIn (PT) — post curto
**Corpo:**

Meça tok/s com o modelo 100% na VRAM vs splill. A diferença é o diagnóstico.
