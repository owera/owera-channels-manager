### 1. r/LocalLLaMA — comment on a fresh thread about MCP tools, plugins, or agent tool loading
The failure mode I keep hitting: the plugin manifest runs a shell before the tool is even loaded. The agent looks idle. The side effect already happened.

If your loader treats the manifest as data, check whether that file is allowed to execute. I broke that down in a short: https://www.youtube.com/shorts/_M1y7vw7Qyo

### 2. dev.to — post
**Title:** Your plugin manifest ran a shell before the tool loaded

**Body:**
Tool schemas are supposed to be declarative. A manifest that shells out during load is an install step hiding inside a config file. The model has not called the tool. The process already ran.

Treat the manifest as data. If something needs a shell, that is a separate, explicit step, with a log line you can see before the agent starts.

Short: https://www.youtube.com/shorts/_M1y7vw7Qyo
