## ch1 Owera Software (EN)

### 1. r/LocalLLaMA — comment on a fresh thread about Copilot credits / “why did paste cost so much”
**Draft:**
A single paste into Copilot Chat is not “one request.” If the clipboard is a 400-file diff or a log dump, the prompt is the paste. 16k credits on Ctrl-V is the model reading what you already had on disk. Same class of bug as leaving Chat open: you pay for context you did not mean to send.

30-second check: paste into a local buffer, trim to the function, then ask. If spend drops an order of magnitude, the meter was the clipboard, not the model.

Short from today:
https://youtu.be/ET73bFYQ1FU

### 2. dev.to — short post
**Title:** Your Copilot onboarding tutorial just spent 14,000 credits
**Body:**
The happy-path tutorial walks you through Chat, inline, and commit messages in one sitting. Each step keeps the previous context. The dashboard still looks “within plan” because billing lags. By the time the invoice lands, the onboarding itself was the first overage.

Fix: finish the tutorial in a throwaway repo, then start real work in a fresh chat. Do not reuse the tutorial thread.

https://youtu.be/ywaYZFu6xAE
