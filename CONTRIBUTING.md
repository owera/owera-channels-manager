# Contributing

Thanks for looking. This repo is MIT.

## Ground rules

Small, focused PRs are welcome. One change per PR. If the change is more than a small fix, open an issue first so we don't waste your time.

Bring tests, or a clear repro, when you can. Be respectful.

## What this is

This is a self-hosted YouTube channel manager. You run it. It is not Owera Cloud. Don't send anyone to a waitlist, and don't write as if Cloud is live.

If you need a public URL, it is [https://owera.com](https://owera.com) — never `owera.ai` or `cli.owera.ai`.

## What to send

A broken install step. A quota edge case. A render failure you can reproduce. A docs typo. That's the useful stuff.

Fork, keep the diff small, open the PR. Link an issue if there is one.
