### 2. dev.to — short post
**Title:** Your agent isn’t “bad at tools” — you hardcoded the connectors
**Body:**
Every time a vendor changes an API, the agent that “just worked” in the demo starts throwing. The usual patch is another adapter. That’s how you end up maintaining ten integrations that all do the same handshake.

MCP is the boring version of that story: one server, one protocol, the model talks to the server. Tool-swap breaks drop because the agent never knew the vendor SDK.
